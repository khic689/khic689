### 🚀 Featured Projects

#### 🗺️ 風格化地圖之路網建構
承接實驗室學長之碩士論文，解決如何從風格化地圖（建案生活機能圖、手繪地圖）中重建出可用道路網路的問題。
- 主導 **SegFormer / U-Net / DINOv3** 架構之系統性比較與消融實驗設計
- 發現小樣本情境下「骨幹越大不一定越好」的反直覺結果，並提出理論解釋
- 團隊將拓樸約束實作為完整流程：路網覆蓋率 **15.5% → 36.0%**
- 已報名 InnoServe 資訊應用服務創新競賽

#### 🛡️ APT 攻擊鏈重建與實作
網路攻防課程專題，以真實 APT 組織為對象重建完整攻擊鏈。
- **Mustang Panda**：主導情資蒐集、建立初始立足點、架設 C2 通道；嘗試提權時因缺乏原始惡意元件改以自製元件測試，最終確認目標環境 UAC 權限隔離機制有效阻斷提權——誠實記錄這次「沒有成功」的診斷過程
- **APT29**：以 Metasploit 完整重建七階段攻擊流程（初始入侵 → 提權 → 憑證擷取 → 橫向移動 → 持久化），於多主機環境逐階段驗證可重現性

#### 🏍️ Portable-IPM 騎乘輔助偵測系統
四人團隊課外專案，結合逆透視映射（IPM）與物件偵測的機車防撞警示系統。
- 負責系統整合層：架設 FastAPI 後端，設計無狀態 RESTful API 串接前端（Flutter）與影像處理模組
- 統一跨語言（Dart / Python）資料格式，封裝固定結構 JSON 介面
- 投稿 InnoServe 競賽

#### 🤖 Fraud-Shield 防詐騙 LINE 機器人
課程專題，團隊開發整合多項 AI 防護模組的防詐騙系統。
- 負責 **Image OCR**（Azure Computer Vision）與 **AI Reasoning**（Google Gemini Pro）模組
- 從複雜截圖擷取文字，交由語言模型輸出具體判斷理由（而非單純是/否的黑箱結果）

#### ⚙️ Simple Compiler 自製編譯器
三人團隊合作，實作完整直譯流程：Lexer → Parser → AST → 環境求值執行，支援變數宣告、算術運算、條件迴圈等語法。
